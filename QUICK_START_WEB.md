# Web Application Deployment Guide

## 1. Quick Start Execution

### 1.1 Backend Orchestration
1.  Navigate to `earthaware/geo-research-assistant/backend`.
2.  Install dependencies: `npm install`.
3.  Initiate service: `npm run dev`.

### 1.2 Frontend Research Portal
1.  Navigate to `earthaware/geo-research-assistant/frontend`.
2.  Install dependencies: `npm install`.
3.  Initiate client: `npm run dev`.

## 2. Infrastructure Access
*   Local Access: [http://localhost:5173](http://localhost:5173)
*   Authentication: `researcher` / `earthaware123`

## 3. Deployment Parameters
Ensure the Python model server is operational on port 8000 before initiating the web application services.
